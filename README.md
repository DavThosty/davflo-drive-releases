# DavFlo Drive – Releases

Hier liegen nur die fertigen Spiel-Builds von **DavFlo Drive** (Windows + macOS) und das Musikpaket.
Das Spiel prüft beim Start automatisch auf neue Versionen und installiert sie selbst.

Manueller Download: unter **Releases** die neueste Version öffnen und die Zip für dein System laden,
dazu `DavFloDrive-Musik.pck` in denselben Ordner wie das Spiel legen.

## Windows: Meldung „Der Computer wurde durch Windows geschützt“
Das Spiel ist (noch) nicht mit einem gekauften Zertifikat signiert, daher warnt Windows beim ersten Start.
Auf **„Weitere Informationen“** klicken, dann **„Trotzdem ausführen“**. Danach kommt die Meldung nicht mehr;
Updates installiert das Spiel selbst.
